# ANKE — фірмовий стиль

Затверджено: 2026-08-01. Обраний варіант вордмарка — **№2 «Couture thin serif»**.

## 1. Логотип

Вордмарк `ANKE` — Cormorant Garamond Light (300), трекінг **0.14em**, тільки великі літери.
Підпис `SHOWROOM` — Jost Light (300), трекінг **0.58em**, великі літери.
Логотип існує лише як **SVG-контури** (текст переведено в криві) — шрифти для його відображення не потрібні.

| Файл | Призначення |

### Правила використання

- У хедері сайту логотип вставляється **інлайновим SVG** (не `<img>`) з `aria-label="ANKE"`.
- Десктоп-хедер: `logo.svg` (з SHOWROOM). Мобільний хедер, фавікон, аватари: `logo-solo.svg` / `logo-mark.svg` — підпис SHOWROOM **вимикається**.
- Охоронне поле: не менше висоти літери «A» вордмарка з усіх боків.
- Мінімальна ширина: `logo.svg` — 120 px; `logo-solo.svg` — 64 px; менше — використовуй монограму.
- Дозволені кольори лого: Ink `#141414`, білий `#FFFFFF`. На фото — тільки біла версія.
- **Заборонено:** рамки (спадок старого лого), тіні, градієнти, розтягування, рожевий як колір лого, будь-які фони під лого крім кольорів палітри.

## 2. Палітра

CSS-змінні (джерело правди — `app/globals.css`, тут — довідник):

```css
--color-ink:        #141414;  /* основний текст, лого, кнопки dark */
--color-paper:      #FFFFFF;  /* фон сторінок */
--color-beige:      #F2ECE4;  /* фонові секції, картки, тайли іконок */
--color-beige-deep: #E7DCCE;  /* межі, розділювачі, акценти секцій */
--color-rose:       #D48CA8;  /* ЄДИНИЙ акцент: кнопки, бейджі SALE, hover */
--color-rose-deep:  #B76E8C;  /* hover/active акцентних елементів */
--color-rose-soft:  #EFD7E0;  /* пудрові плашки, фони бейджів */
--color-muted:      #6B6459;  /* другорядний текст на світлому */
```

Правила:

- База інтерфейсу — **монохром + беж**. Рожевий (`rose`) — тільки акцент: CTA-кнопки, бейджі знижок, hover-стани, прогрес-бар безкоштовної доставки. **Ніколи як фон сторінок чи секцій** (спадок старого лого — не повторювати).
- Текст на `rose` — білий; перевірено на контраст для великих елементів. Дрібний текст на rose не ставити (контраст WCAG AA недостатній) — для дрібного використовувати `rose-deep` на світлому фоні.

## 3. Типографіка

| Роль | Шрифт | Накреслення |
|---|---|---|
| Дисплейні заголовки (h1–h2, hero, ціни на картці) | **Cormorant Garamond** | 300 (Light), 500 (Medium) для чисел |
| Текст, UI, кнопки, навігація | **Jost** | 300/400/500 |
| Лейбли, кнопки, «SHOWROOM»-стиль | Jost, uppercase, трекінг 0.12–0.2em | 400 |

- Обидві сім'ї підтримують кирилицю; self-hosted через `next/font/local`, субсети latin + cyrillic, `display: swap`. Максимум 2 сім'ї — це вимога перформансу.
- Ліцензія обох шрифтів — SIL Open Font License (комерційне використання дозволено).
- Типографічна шкала (базис 4px): 12 / 14 / 16 / 18 / 21 / 26 / 32 / 40 / 52 / 68.

## 4. Настрій

Багато повітря, великі поля, мала амплітуда анімацій, повільний рух. Референси: мінімалізм Katsurina, структура NYS. Логотип ніколи не «кричить»: він маленький, впевнений і завжди в одному з двох кольорів.
